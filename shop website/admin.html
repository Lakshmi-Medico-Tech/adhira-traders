How to set up cPanel MySQL Database for Production:
  1. Log in to your cPanel → click MySQL Databases (or MySQL Database Wizard).
  2. Create a new database (e.g., youruser_crackers).
  3. Create a new user with a strong password (e.g., youruser_admin).
  4. Crucial Step: Under "Add User To Database", select the user and database, click Add, and check ALL PRIVILEGES → Make Changes.
  5. Enter the database name, username, and password above and click "Save Credentials to config.php".
  6. Click "1-Click Sync to MySQL" — this creates all database tables (products, categories, orders, combos, giftboxes, banners, settings) and migrates all 127 products and current data instantly!
